# 🇸🇦 رِواء AI (Rewaa AI) - صوت الجيل السعودي الرقمي

> **مشروع مشارك في مسابقة أعمال اليوم الوطني السعودي 96**  
> *تنظيم: النادي الطلابي بكلية الأعمال والاقتصاد*

---

## 🌟 Concept | فكرة المشروع

**رِواء AI** هي شخصية سعودية افتراضية تفاعلية مدعومة بنماذج الذكاء الاصطناعي المتقدمة من Google (Gemini 3.7 Flash / Gemini Flash). تمثل "صوت الجيل السعودي الرقمي"، وتتيح للزوار والطلاب التفاعل المباشر معها صوتيًا ونصيًا وبصريًا للاحتفاء باليوم الوطني السعودي 96، واستعراض التنوع الثقافي والتاريخي لمناطق المملكة الـ 13، واستشراف الطموحات الوطنية نحو رؤية السعودية 2030.

المشروع مصمم ليكون تجربة ويب حية ومتكاملة (Interactive Web Experience)، وليس مجرد فيديو مسجل أو روبوت محادثة تقليدي.

---

## ✨ المميزات الرئيسية (Features)

* 🎙️ **محادثة صوتية عربية مباشرة (Voice Conversation)**: التحدث بالصوت باستخدام الميكروفون باللهجة السعودية الطبيعية (`ar-SA`).
* 🔊 **نطق ذكي للردود (Text-to-Speech)**: الاستماع إلى الردود بنبرة صوتية متناسقة وطبيعية مع إمكانية كتم أو إعادة الاستماع.
* 🎭 **حالات بصرية تفاعلية للشخصية (Interactive Character States)**:
  * `IDLE` (مستعدة للحوار في وضع طبيعي).
  * `LISTENING` (استماع بموجات صوتية متوهجة وتفاعل حي).
  * `THINKING` (معالجة السؤال واستحضار الرد بالذكاء الاصطناعي).
  * `SPEAKING` (تحدث الشخصية مع حركة فم ومؤشر ترددي نابض).
  * `ERROR` (تنبيه لطيف بالعربية عند تعذر التقاط الصوت أو انقطاع الاتصال).
* 🇸🇦 **تجربة "صوتنا يصنع المستقبل"**: تجربة تفاعلية تستمع لطموح المستخدم لمستقبل المملكة، يحللها Gemini AI ويحولها إلى بطاقة طموح موجزة تخلد في جدار الطموحات الرقمي.
* 💡 **أسئلة مقترحة جاهزة**: خيارات سريعة لاستعراض تراث نجد، تاريخ القصيم، الذكاء الاصطناعي، ومسابقات تاريخية سريعة.
* 🔒 **أمان متقدم وحماية البيانات**: وسيط برمجي (Backend Proxy) يحمي مفاتيح API بالكامل دون كشفها في المتصفح، مع احترام تام للخصوصية وعدم تخزين أي بيانات شخصية تعريفية.
* 📱 **تصميم عصري متجاوب بالكامل (Mobile-First / Responsive)**: متوافق مع كافة الأجهزة (الهواتف، الأجهزة اللوحية، والحواسيب).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend)**: React 18, TypeScript, Vite.
* **التصميم والأنماط (Styling)**: Tailwind CSS, Lucide Icons, Glassmorphism UI.
* **محرك الذكاء الاصطناعي (AI Engine)**: Google Gemini API (`@google/generative-ai`) مع دعم Gemini 3.7 Flash و Gemini 2.5 Flash.
* **الخادم البرمجي والوسيط (Backend Proxy)**: Node.js, Express.js, CORS.
* **الصوتيات والتعرف الصوتي**: Web Speech API (SpeechRecognition + SpeechSynthesis) مع ترددات صوتية مرئية.

---

## 🤖 تكامل Gemini والذكاء الاصطناعي (Gemini Integration)

تم بناء الشخصية لتعتمد على النموذج المحدد في المتغير البيئي `GEMINI_MODEL`:
* النموذج الافتراضي: `gemini-2.5-flash` أو `gemini-3.7-flash` (حسب المتاح في مفتاح API الخاص بك).
* تم ضبط **System Prompt** محكم يعكس الهوية السعودية، الود، الثقافة، والموضوعية، مع التأكيد الصريح على أنها شخصية افتراضية تعمل بالذكاء الاصطناعي عند سؤالها.

## 📦 التثبيت والتشغيل المحلي (Installation & Running Locally)

### 1. استنساخ المشروع (Clone Repository)
```bash
git clone https://github.com/your-username/rewaa-ai-saudi96.git
cd rewaa-ai-saudi96
```

### 2. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 3. إعداد المتغيرات البيئية (Environment Variables)
قم بإنشاء ملف `.env` في المجلد الرئيسي عبر نسخ الملف النموذجي:
```bash
cp .env.example .env
```
ثم افتح ملف `.env` وضع مفتاح API الخاص بك من [Google AI Studio](https://aistudio.google.com/):
```env
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-2.5-flash
PORT=3001
```

### 4. تشغيل المشروع بالكامل (Fullstack Mode)
لتشغيل الخادم الخلفي (Backend) وواجهة المستخدم (Frontend) معًا بأمر واحد:
```bash
npm run fullstack
```
أو تشغيلهما في نافذتين منفصلتين:
* **الخادم الخلفي:** `npm run server` (على المنفذ 3001)
* **الواجهة الأمامية:** `npm run dev` (على المنفذ 5173)

افتح المتصفح على: `http://localhost:5173`

## 🔒 الأمان والخصوصية (Security & Privacy)

1. **حماية المفاتيح**: يتم تمرير كافة استدعاءات Gemini عبر الخادم `server/index.ts`. لا يوجد أي مفتاح API مكشوف داخل ملفات الـ React أو الـ JavaScript أو الـ HTML.
2. **استبعاد الملفات السرية**: تم إدراج ملفات `.env` في `.gitignore` لمنع رفع أي أسرار إلى GitHub.
3. **حفظ الخصوصية**: لوحة "صوتنا يصنع المستقبل" لا تجمع أو تخزن أي بيانات شخصية (مثل الاسم، رقم الهاتف، أو البريد الإلكتروني).

## 🚀 النشر على السحابة (Deployment)

### النشر الموحد (Production Build & Run)
```bash
npm run build
npm start
```
سيقوم الخادم بتشغيل الـ API وتقديم ملفات الواجهة من مجلد `dist/`.

### النشر على منصات الاستضافة (Render / Railway / VPS / Vercel)
* اضبط المتغيرات البيئية في لوحة تحكم المنصة (`GEMINI_API_KEY` و `GEMINI_MODEL`).
* أمر البناء (Build Command): `npm run build`
* أمر البدء (Start Command): `npm run server`
